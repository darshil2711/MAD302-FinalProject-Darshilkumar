## Description
A multi-screen Android application built with Kotlin that allows
users to view, add, edit, and delete products. Simulates a
real-world inventory management system.

## Features
- Product list using RecyclerView with CardView items
- Product detail screen with Intent data passing
- Add product form with validation
- Edit product functionality
- Delete product with confirmation dialog
- Navigation between all screens

## Tech Stack
- Language: Kotlin
- UI: ConstraintLayout, RecyclerView, CardView
- Data Model: Product(id, name, price, description)
